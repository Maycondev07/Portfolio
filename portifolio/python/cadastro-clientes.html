Sistema de Cadastro de Clientes

GitHub

Aplicação em Python, via terminal, para cadastro e consulta de clientes em uma base de dados local. Este projeto foi desenvolvido com o objetivo de praticar:

  • Lógica de programação
  • Python
  • Banco de dados SQLite
  • CRUD (cadastro e consulta de registros)
  • Consulta por ID, CPF ou CNPJ
